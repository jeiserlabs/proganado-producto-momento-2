Datos demo

Del formulario a SQLite, sin misterio

El formulario envía los datos por POST. Python los valida con consultas parametrizadas y SQLite los guarda en un archivo local. Luego la página los vuelve a leer y los muestra en una tabla.

  1. 1
    Escribes los datos
    Arete, nombre, raza, peso y estado.
  2. 2
    Python valida y guarda
    Consulta parametrizada: sin concatenar SQL.
  3. 3
    La tabla relee
    SELECT, filtro por texto y por estado.
Probar el módulo SQLite
SQLite · schema local 
CREATE TABLE bovinos (
  id INTEGER PRIMARY KEY,
  arete TEXT UNIQUE NOT NULL,
  nombre TEXT NOT NULL,
  raza TEXT NOT NULL,
  peso_kg REAL NOT NULL,
  estado TEXT NOT NULL
);

La demo no guarda contraseñas ni datos personales: solo registros de bovinos.
